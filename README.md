# Supply Chain Q&A Agent

An AI-powered Supply Chain Question & Answer system built using
Python, FastAPI, RAG, LangChain, LangGraph, FAISS, and LLMs.

## Project Goals

- Answer supply-chain questions using structured data and documents
- Retrieve relevant information using RAG
- Use an agent to route questions to appropriate tools
- Provide grounded answers with source references
- Evaluate retrieval and answer quality
- Expose the system through REST APIs
- Deploy the application using Docker and Render
